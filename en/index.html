Questions

What to know before starting

Is SKVOZNYAK a CRM?

SKVOZNYAK is primarily a marketing intelligence and decision platform. CRM integrations and new CRM modules are scoped separately.

What ad platforms can connect?

The architecture targets Meta, Google, TikTok and other channels. Each connection is confirmed based on API access and permissions.

Can we see a demo first?

Yes. We can walk through an interface using illustrative data and then define a suitable pilot.

Does data refresh automatically?

For supported APIs, data can sync automatically. Frequency and historical coverage depend on the connected provider.

Is every feature live today?

SKVOZNYAK is in pilot development. Features roll out in stages, and the delivered scope is agreed before onboarding.
