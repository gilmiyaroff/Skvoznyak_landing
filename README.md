# SKVOZNYAK — Landing pages

Публичный репозиторий маркетингового сайта SKVOZNYAK. Программа (backend, CRM/attribution, PostgreSQL) разворачивается **отдельно на VPS** и **не входит** в этот репозиторий.

## Содержимое

- `index.html` — казахская главная страница `skvoznyak.kz/`
- `ru/index.html` — русский язык `skvoznyak.kz/ru/`
- `en/index.html` — английский язык `skvoznyak.kz/en/`
- `kz/index.html` — совместимость: перенаправление старого `/kz/` на главную.
- `assets/styles.css` и `assets/site.js` — адаптивный интерфейс и форма
- `assets/skvoznyak-logo.webp` — фирменный логотип из существующих материалов SKVOZNYAK
- `functions/api/lead.js` — обработчик заявок для **Cloudflare Pages Functions**
- `privacy/`, `ru/privacy/` и `en/privacy/` — предварительные тексты о персональных данных. Старый `/kz/privacy/` перенаправляется на `/privacy/`.

**Не храните токены, ключи API и реальные данные пользователей в публичном репозитории.**

## Публикация через Cloudflare Pages

1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git.
2. GitHub repository: `gilmiyaroff/Skvoznyak_landing`.
3. Production branch: `main`.
4. Framework preset: **None**.
5. Build command: **пусто** (для статического HTML сборка не нужна).
6. Build output directory: `.` (корень репозитория).
7. После первого deployment подключите custom domains `skvoznyak.kz` и `skvoznyak.com`. Убедитесь, что DNS каждого домена направлен на Pages по подсказкам Cloudflare.
8. Корень `.kz` показывает KZ, `/ru/` — RU, `/en/` — EN. При открытии корня `.com` пользователь перенаправляется на `/en/` этого домена.
10. Канонические адреса всех трёх версий указывают на `skvoznyak.kz`; старые ссылки `/kz/` и `/kz/privacy/` имеют HTML-перенаправление.
9. Переключатель в шапке: **KZ · RU · EN**, без флагов. Он поддерживается на всех лендингах и страницах конфиденциальности.

После успешного подключения push в `main` автоматически публикует новые версии страниц. Preview branches можно тестировать отдельно.

## Обработка заявок

Форма отправляет POST на `/api/lead`. Она **не собирает заявки до настройки** двух защищённых секретов в Cloudflare Pages → Settings → Variables and Secrets:

- `TELEGRAM_BOT_TOKEN` — токен созданного для проекта Telegram-бота.
- `TELEGRAM_CHAT_ID` — ID чата, куда бот вправе писать.

Не помещайте значения в GitHub или `index.html`. Создайте их как **Secrets** для production environment, затем повторно разверните проект. Проверьте форму с реальным тестовым номером; успех отображается только после подтверждения API Telegram.

При отсутствии настроек сервер отвечает HTTP 503, а интерфейс не заявляет об успешной отправке. Для промышленного запуска рекомендуется дополнительно включить Cloudflare Turnstile и ограничение частоты запросов.

## Перед публичным запуском

- [ ] Указать юридическое имя оператора данных, контактный email, срок хранения и условия передачи данных в `privacy/index.html`, `ru/privacy/index.html` и `en/privacy/index.html`.
- [ ] Проверить соблюдение применимых правил обработки персональных данных в Казахстане, включая использование зарубежного мессенджера.
- [ ] Настроить Telegram secrets и отправить тестовую заявку с `skvoznyak.kz/`, `skvoznyak.kz/ru/` и `skvoznyak.kz/en/`.
- [ ] Проверить мобильную верстку, все три локализации и ссылки.
- [ ] Убедиться, что Pages проект не конфликтует с `staging.skvoznyak.kz` и будущим `app.skvoznyak.kz` на VPS.

## Проверка локально

Для просмотра статической части:

```bash
python3 -m http.server 8000
```

Открыть `http://localhost:8000` и `http://localhost:8000/en/`. Обработчик `/api/lead` при таком запуске работать не будет — для этого нужен Cloudflare Pages Runtime.

Демонстрационные показатели на экранном макете не являются реальными результатами клиентов.


## Галерея интерфейса

На всех трёх языках расположен интерактивный блок `#screens` с двумя SVG-экранами:

- `assets/showcase-overview.svg` — общая рабочая панель маркетинга.
- `assets/showcase-meta-ads.svg` — таблица объявлений Meta Ads.

Это **векторные визуализации интерфейса на синтетических данных**, а не точные экспорты из запущенного backend или снимки реальных клиентов. SVG обеспечивает масштабирование без пикселизации; иллюстрации подготовлены по дизайн-референсам SKVOZNYAK. Основной экран использует `showcase-overview.svg` вместо ранее нарисованного статичного мини-дашборда. Переключение между примерами и модальный просмотр реализованы в `assets/site.js`. Визуальные стили — в `assets/styles.css`.


## Отдельный лендинг ChatGPT Ads

- `gptads/index.html` → `https://skvoznyak.kz/gptads/` (казахский по умолчанию).
- `gptads/ru/index.html` → `https://skvoznyak.kz/gptads/ru/` (русский).
- `gptads/en/index.html` → `https://skvoznyak.kz/gptads/en/` (английский).
- Старые `/ru/gptads/` и `/en/gptads/` оставлены как HTML-перенаправления.
- Стоимость ведения: 100 000 ₸ в месяц, размещение оплачивается отдельно; пример стартового бюджета $25 в день / $175 за 7 дней при USD-биллинге (проверяется в рекламном кабинете).
- `assets/gptads.css` и `assets/site.js` — общие технические ресурсы, но страницу GPT Ads можно открывать без посещения главной.

**Важно для Cloudflare Pages:** подключение репозитория само по себе не гарантирует, что сайт получил последнюю версию. При 404 после изменения `main` проверьте Production Deployment и branch `main` в Cloudflare → Workers & Pages → Deployments. Убедитесь, что свежий deployment включает `gptads/ru/index.html`, `gptads/en/index.html` и обновлённый `sitemap.xml`. Не публикуйте сквозь Github Pages и не заменяйте DNS существующего сайта.

## Визуальное облако интеграций

- `index.html`, `ru/index.html`, `en/index.html`: строка сервисов заменена на адаптивный блок с 13 источниками.
- `assets/integration-icons.svg`: локальный SVG-спрайт узнаваемых логотипов (из Simple Icons); у остальных сервисов используются текстовые бренд-бейджи вместо непроверенных логотипов.
- `assets/integrations.css`, `assets/integrations.js`: стили, анимация и лёгкий parallax на scroll, без тяжёлых библиотек.
- На небольших экранах — компактная сетка; `prefers-reduced-motion` отключает анимацию.
- Бейджи иллюстрируют целевую экосистему, а не гарантируют готовность всех API-интеграций. Доступность указывается под блоком.

## Группировка облака интеграций и GA4/Wazzup

Основной лендинг на казахском, русском и английском языке содержит 15 сервисов в группах: реклама (Meta Ads, Google Ads); медиа (YouTube, TikTok, Instagram, Telegram); CRM и коммуникации (amoCRM, Bitrix24, WhatsApp, Wazzup, Sipuni, Kelesu); сайты и аналитика (Tilda, Google Analytics 4, Google Sheets). GA4 использует локальный SVG-знак. Wazzup пока отображается текстовым бренд-бейджем. Анимации отключаются при настройке reduced motion. На сайте указано, что доступность коннекторов определяется отдельно.
