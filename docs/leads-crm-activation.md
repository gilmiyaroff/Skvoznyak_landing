4. In marketing Cloudflare Pages production settings configure four secrets: `CRM_INGEST_TOKEN`, `CF_ACCESS_CLIENT_ID`, `CF_ACCESS_CLIENT_SECRET`, and optionally `CRM_INGEST_URL` (validated as an HTTPS URL at the CRM hostname). The ingest token value must match the server value.
5. Complete privacy policy legal entity, purposes, retention and legal assessment of data transfers. Add public form rate limiting / Turnstile.
6. Merge this PR only when all gates are complete and redeploy Pages.
7. Send **synthetic** test requests from RU, KZ, EN, GPT Ads landing variants, confirm one card in CRM per request and source attribution.
8. Test the new "custom integration" request button: it must select interest `integration`, show a required service name and record it in the CRM.

No Telegram messages are generated by this revised endpoint. No contacts are stored in GitHub, Cloudflare D1, or browser local storage; only non-personal UTM campaign tags may be kept in session storage.
