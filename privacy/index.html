Политика конфиденциальности

Версия для предварительного ознакомления. Перед началом публичного сбора персональных данных владелец сайта должен указать свои юридические реквизиты и контакт для обращений по персональным данным.

1. Какие данные мы получаем

При отправке заявки пользователь самостоятельно указывает имя, номер телефона / WhatsApp, наименование компании (необязательно) и тему обращения. Для работы сайта технические провайдеры могут обрабатывать технические данные соединения.

2. Для чего нужны данные

Мы используем контактные сведения исключительно для обработки запроса на демонстрацию, консультацию или подключение SKVOZNYAK и для обратной связи по этому запросу. Не публикуем данные заявки в открытом доступе.

3. Как передаётся заявка

При настройке формы информация передаётся через защищённый обработчик Cloudflare Pages в Telegram, где сообщение доступно назначенному получателю. Передача данных этому провайдеру может включать трансграничную обработку. Пользователь должен учитывать это при предоставлении согласия.

4. Хранение и удаление

На сайте не предусмотрено хранение заявки в локальной базе данных. Срок хранения сообщений в сервисе-получателе устанавливается оператором данных и должен быть закреплён до публичного запуска. Пользователь вправе обратиться к оператору с запросом об удалении данных и другими обращениями в порядке применимого законодательства.

5. Контакт оператора

До публикации необходимо заполнить: наименование / ФИО оператора, контактный email для запросов, адрес (при необходимости) и срок хранения заявок. Без этих сведений политика не является окончательной.
